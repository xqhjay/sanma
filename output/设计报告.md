## 2. 优化方法论

### 2.1 问题建模（关键发现）

**指标的决定机制**（从字劫源码逆向验证）：

1. **二码字 = 前缀冠军**。某字的二码（首二码）若在其码表组内频次第一（或为二简字），它就是二码字。
   前 1500 二码字数 = |{前缀 P : P 的 kc6000 冠军 ∈ 前 1500}|。基线 563 意味着有 113 个前缀的
   冠军被 1501 名之后的低频字占据。
2. **出简重 = 三码组内非首位**。组贡献 = |组| - 1 - [组含二简字]；二简字永不计出简重。
   总出简重 = 6000 - 不同三码数 - 676。
3. **硬约束** 前 1500 出简重 = 0 ⟺ 每个前 1500 字是二简，或是其三码组内频次最高的非二简字。

因此优化本质是**组合优化**：把 240 个归并组的大码重新分配到 26 个键上，使 top6000 的
（前缀, 全码）二维分布最大程度分散、且高频字尽可能占据前缀冠军位。

### 2.2 为什么"副根提升"是最大杠杆

官方 1.2 有 240 个归并组（26×26=676 个码位仅用 240 个，其余 436 个码位闲置）。
而大量超高频副根（如 阝、刂、攵、忄、白、囗）与主根共用码位，导致：
- 含这些副根的字全部挤进同一码位的三码组 → 出简重
- 这些副根无法作为前缀首码 → 无法产生二码字

将高频副根**提升为独立字根组**（新码位小码按其自身读音音托），一举获得：
- 43 个新前缀源 → 直接制造新二码字（+92 的主要来源）
- 高频三码组被拆散 → 1501~3000 区间出简重清零

额度检查：240 + 43 = 283 ≤ 320（约束 4），仍有 37 组余量。

### 2.3 两阶段优化算法（参考 code_genie 模拟退火框架）

**阶段一：候选生成与 SA 重排**

```
输入：官方 1.2 布局（温启动）+ 43 个提升候选（按使用频次筛选）
变量：240 基组大码 K(g) ∈ 26键 + 每候选的提升开关与新键位
邻域：单组移键 / 两组换键 / 提升开关翻转 / 提升根换键
评估：O(n) 快速评估器（预计算 6000 字 seq，数组化前缀冠军/三码组计数），单次 <0.5ms
退火：T 从 T0 几何降温，Metropolis 接受，周期性全量重评校准防状态漂移
目标：score = 3000·cd2_1500 + 40·w2_1500 - 5000·sc_1501_3000 - 300·sc_total
      - 1e9·[sc_1500 > 0]（硬约束罚项）
```

并行跑 A~F 六组权重配置（w2 与 scTotal 权重平衡不同），最终 **F 配置**全指标帕累托最优：
四项主指标同时改进且无回退。

**阶段二：码表生成与简码分配**

- 二简分配：每前缀选冠军字（若冠军被一简占用则顺延），保证前 1500 零出简重
- 四二顶表：无一简，`全码\n二简码` 双行结构，组内按官方行序规则（非二简频序在前、二简殿后）
- 三定表：一简 + 二简 + 全码，一简字取 26 个最高频字
- 交叉验证：自产码表喂回字劫测评，与 SA 评估器逐指标对账一致

### 2.4 音托规律（保持官方体系）

小码全部维持官方音托不变（大小码中仅大码重排），规律：

1. **声母托**：取主根声母首字母，ch→c、sh→s（车 che→c、山 shan→s）
2. **z/zh 声母**：取韵母首字母（中 zhong→o、之 zhi→i、子 zi→i）
3. **整读托**：yi→i、wu→u、yu→v
4. **新增 43 个独立根**：小码 100% 按自身读音音托（氵无独立音除外的不选）

音托合规率 **244/258 = 94.6%**（基线 93.9%）。14 组"不合规"中多数为多音字取音差异
（见 xian、长 zhang、车 ju），实际按常用音均合规。

## 5. 使用方式

**四二顶**：码表不含一简。输入第四码时顶前二码对应字上屏，三码字空格上屏。
**三定**：码表含一简二简。一简二简字空格上屏，单字最多三码。
两表可同时安装（Rime 方案级切换），字根布局完全一致。

## 7. 结论

在不破坏奕码"大码乱序、小码音托、三码形码"骨架、保持全部官方拆分与音托规律的前提下，
通过 **43 个高频副根提升 + 240 组大码模拟退火重排**，四大关注指标全面改进：

- 前 1500 二码字 **563 → 655**（+16.3%，超额完成 ≥580 目标）
- 前 1500 二码加权 **70.06% → 73.19%**（+3.13pp，达标 ≥73%）
- 1501~3000 出简重 **5 → 0**（清零）
- 前 6000 出简重 **324 → 323**（微降，已逼近 676 码位编码空间的理论下界）
- 硬约束全部保持：前 1500 出简重 = 0、283 组 ≤ 320、音托合规率不降反升

优化版可直接以 Rime 码表 + hanzi-chai 字根方案投入实用。
